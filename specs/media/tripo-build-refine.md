## Routing and credits

Run `python3 scripts/engineering-harness/tripo-capabilities.py` to discover tool names and generation enums through the registered Studio OAuth server. Use Codex MCP registration with endpoint `https://msapi.tripo3d.ai/mcp` and client ID `studio-codex`. Inspect the live schemas for model enums before submission. The authenticated session on this campaign returned 39 tools. Prefer supported MCP operations and use the connected Studio tab for H3.5 and account-specific price checks. Each new charged operation needs a matching scope, quote and available authorized amount. Reserve each attempt once, keep its idempotency key and receipt, reconcile incomplete submissions before any retry, and never commit upload grants or signed downloads. The additional 80-credit cap covers both accessories’ UV and texture together. Rig, animation, PBR and generation have no allocation from that cap.

For compatible humanoids use the local audited Charakuru release. Its finished-model body-replacement route preserves untouched data. Use its rig, donor transfer, expression and spring workflows within license terms, and its VRM exporter. The installed v1.1.1 matched 296 manifest entries. The optional 26 facial poses require authored input keys. The bundled scripts, donors and expressions stay in the separately licensed installation. Check eligibility for business use under custom license v1.2, including both JPY 100M thresholds. The repository-owned inspector reads hashes and local capabilities.

## Optional C-H35

Preserve A/B/C/D and the original Icarus body. Start with approved Phoenix Bow, wings, armor or S-class Pet surfaces. Use `scripts/art/blender_icarus_h35_transfer.py` for pinned same-part comparison, bidirectional distances, normal-facing rays, misses and atlas overlap before baking. For bow part 16, a private 1024-square tangent normal bake after local re-unwrap had 295,677 hit pixels and 0.0571% misses. The original chart overlapped four texels. The independently generated negative control and the incomplete string failed correspondence. This validates a local bake technique on one part. Compare material-on/off in matched Unity views and profile it before accepting the visual benefit and production cost.

### Verified Icarus delivery

Both Smart UV tasks and both four-reference texture tasks succeeded. Native outputs preserved the wing's 17,782 triangles and 104 joints. The bow retained its draw target and returned 4,989 triangles, two fewer than the original. Its body texture is 4096 square and its string texture is 512 square. The owner reviewed the native surfaces on both models. The provider stripped the bow's empty grip marker. Restore its source placement after checking both meshes’ coordinate bounds.

Preserve downloaded GLBs. If the installed Blender importer lacks the meshopt decoder, expand buffer views with `scripts/art/decode_tripo_meshopt.mjs SOURCE NEW_GLB DECODER_MODULE` using the installed meshoptimizer JS module. Render both sides with `blender_review_tripo_surface.py` and decode the embedded images with `inspect_tripo_surface.py`. For private Unity fitting use `blender_stage_tripo_accessory.py`; it restores the bow anchor, converts quantized accessors and verifies original texture bytes. Owner surface approval precedes placement, draw/fold and performance qualification.

For a paired visual check run Blender 5.3 with factory startup, disabled auto-execution and a private user-resource directory. Use `blender_compare_h35_detail.py STUDY NEW_DIRECTORY`, then `python3 scripts/art/measure_h35_detail.py NEW_DIRECTORY`. On the Phoenix Bow part 16, side-view mean absolute RGB error against the high-poly source dropped from 12.18 to 2.46 code values; oblique error dropped from 11.99 to 2.87. The normal changed zero silhouette pixels in these views. The visible improvement was recovery of the beveled facets. The first run loaded a host render add-on and failed the common-opaque-foreground check. Keep the original bake and review the normal on the final colored material at character distance before adoption.
