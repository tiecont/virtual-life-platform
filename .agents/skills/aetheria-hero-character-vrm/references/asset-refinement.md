# Controlled refinement of an approved character

Start with the manifest-pinned VRM, the existing authored motion, a named visual defect and its original scene capture. Retain original files read-only. On Icarus, use Blender 5.3 in background with `--python-exit-code 1 --python scripts/art/audit_icarus_source.py -- ORIGINAL.vrm NEW_REPORT.json`. Inspect the per-primitive geometry, skin, UV and surface data, and open the original renders at their intended size. Polygon count and apparent texture resolution cannot establish likeness or edge flow. Inspect framing and shader import before editing source topology.

Use the installed Unity Editor directly with `Aetheria.Editor.IcarusLocalizedGarmentStudy.CaptureRefinementABC`. Its private inputs are the same original VRM, shoulder-clearance walk clip, paired position cache and hashed mask used by `BuildBodyLayersRendered`. Set absolute paths in `AETHERIA_GARMENT_BASE_CLIP`, `AETHERIA_GARMENT_BASE_POSES`, `AETHERIA_GARMENT_LOCAL` and a new `AETHERIA_GARMENT_OUTPUT`. The A/B/C folders and native readback belong in the run's ignored evidence directory. A uses the original mesh/materials. B renders the same actor at 1440 square and resolves to the same 720-square frame. C uses the identical rendering path with the private undercloth mesh and corrective track. Compare face, chin, garment and full-body frames at matching times. Use B-repeat to measure capture repeatability and C-partition with the corrective muted to isolate changes from the new submeshes. Run `python3 scripts/art/compare_refinement_frames.py CAPTURES NEW_REPORT.json` to compare all 16 fixed views per condition and hash the inspected images. The portrait is sampled at 85% of the walk. Read back protected vertices, frame bounds and foreground values. Review changes at an edge or contact that motivated the work.

Once component gates permit, render D with the accepted body and complete performance. Match pose, camera, light and resolution for the technical comparison. Capture the separately directed cinematic and include its source Timeline, sound and runtime-player benchmark. A previous offline video with an unrefined actor serves as historical evidence only.

Escalate from import/lighting to material masks, localized deformation and selective topology work according to the observed cause. A face with painted details and empty morph bindings needs measured eyelid/lip geometry before facial animation. Preserve the approved texture and UVs on a derivative, check symmetry and return to neutral, and compare the result against the original identity. Record every acceptance finding using the [Hero, Pet and Boss rubric](../../../../specs/acceptance/character-visual-fidelity.md).
