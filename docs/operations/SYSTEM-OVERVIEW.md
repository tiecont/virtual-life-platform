# System and traffic observation slice

The System & traffic tab reads a fixed private aggregate observation through the operator BFF. It keeps the original Overview and existing application behavior. `GET /api/admin/observations?view=system&range=current` accepts this exact read only; callers cannot choose a URL, metric query, range, credentials or labels. The BFF authenticates the operator before and after even cached/coalesced reads, retains a5second fetch budget and bounds source body/time/redirects. The telemetry credential remains server-only.

A current sample is FRESH through10seconds, STALE through30seconds, UNKNOWN thereafter or with invalid clocks/schema/source. A failed read can retain a recent sample as STALE; it cannot manufacture zeros. The browser also expires samples locally. The projection is aggregate-only, with schema/source/sample/process timestamps and explicit cumulative duration semantics. The displayed system map is configured repository architecture; observed coverage is separate. Counts on a different edge or a successful order query are not inferred as link health, worker liveness or whole-database health.

This is an IN_PROGRESS N07-04 slice. Local process HTTP/socket/member/room-command/hospitality and event-loop observations are wired. Database health/pool/waits, worker backlog/liveness, deployed image/build versions, and platform admission queue observations are not connected in this slice and display UNKNOWN/not implemented. Next local slice must add bounded owner ports and coverage for available sources. An actual staging scrape remains a separate unmet gate behind N04-04; a loopback/private production-mode scrape is not staging qualification.

Qualification distinguishes actual backend/production-image MFA/TLS flows from labeled synthetic browser zero/stale/missing/error fixtures. No production capacity, deployment, physical-device, iOS or public/store result follows. Preserve one room owner, separate worker, existing privacy and release gates. Disable the read-only tab/private proxy on rollback without changing gameplay or deleting evidence.
