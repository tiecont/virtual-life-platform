# Private admin runtime artifact

`infra/docker/Dockerfile.admin` builds the existing admin application with the frozen monorepo toolchain and packages its Next standalone closure. The runtime starts from the same pinned clean Node base as API/web, removes package managers, runs as `node`, and listens on3400. It contains no API/portal application, database migrations, workspace source tree, tests or development dependency installation. Its package inventory/SBOM is derived from actual packaged manifests, not the workspace lockfile alone. The inspector checks real paths, file hashes, credential patterns, static JS/CSS, backend/development package exclusion and a denied filesystem write under read-only execution. This is not a CVE scan or signed supply-chain attestation.

Configure `ADMIN_ORIGIN` as an exact HTTPS origin and `ADMIN_API_ORIGIN` as the fixed private API origin at runtime. `ADMIN_METRICS_READ_TOKEN` is an optional64-character lowercase hex read credential used only by the server BFF. Missing credentials produce metrics UNKNOWN; a present malformed credential rejects startup. Missing/invalid origins also reject image startup with a generic message. The entrypoint and BFF share one parser. Normal development/unconfigured BFF behavior remains503. Never supply operator encryption keys, database credentials, player session keys or cluster credentials to this image. Keep values out of Docker build arguments and public environment variables.

The build uses explicitly synthetic origin/token markers. The actual image scanner rejects those markers and `/internal/telemetry` in browser assets. No build configuration becomes image runtime environment. Production CSP uses a fresh request nonce without unsafe-inline/eval; responses remain private/no-store, noindex, frame-denied and no-referrer. Authentication, CSRF, bounded typed requests, metrics freshness/query budget and operator audit remain owned by the existing N07-01/N07-02 boundaries.

Run `pnpm image:check --target=admin` or append `--source-revision <exact40hexSHA>`. The command archives that immutable source, builds/inspects the image, verifies sanitized invalid-configuration failures, checks a same-source API image, then runs `scripts/admin-image-smoke.mjs`. The release bundle may reuse already completed same-source API facts; it still exercises the admin against that exact API image. A script's presence is not evidence that it passed.

The smoke owns an isolated Compose project/database/network and generated local TLS certificate. API/admin/database have no published ports; only the TLS edge binds loopback. Its edge rejects backend/player/socket/internal routes and proxies the admin frontend/BFF. It provisions one synthetic operator using the actual API image's out-of-band CLI with owner-only tmpfs files, waits for genuinely fresh TOTP counters, then exercises six scenarios: private/read-only runtime; TLS/CSP/unauthenticated denial; desktop/mobile browser MFA, metrics and audit; credential/Origin/CSRF/query boundaries; actual step-up rotation; and same-image runtime configuration restart, UNKNOWN on invalid read credentials, revocation and unaffected API readiness. Browser mobile emulation is not physical Android evidence. The fixture deletes its generated secrets, container data and network in cleanup; raw logs/screenshots stay private.

The source-bound Quality job now requires API/web/admin image results. Release schema2 contains all three immutable image descriptors, per-artifact matching source SHA, SBOM/provenance, compatibility bounds and actual six-scenario checks. Schema1 pairs remain valid historical inputs. Publishing and manual promotion stay independently disabled. Local loopback registry rehearsals are explicitly marked and cannot validate as genuine release candidates. No real operator, private ingress, hosted publisher or deployment is created by this task.

Rollback preparation: retain the prior tested admin digest and source-bound release bundle. An operator may select that compatible prior admin image while retaining current API/schema only after confirming the recorded protocol/schema window and replaying private authentication/session/audit/metrics checks. Disable private admin ingress during uncertainty and revoke operator sessions when indicated by the incident procedure; preserve append-only audit. No down migration, automatic release or new deployment authority follows from image verification. First-admin installation has no preexisting admin digest; close its ingress instead. N07-05 owns actual private deployment/rollback qualification.
