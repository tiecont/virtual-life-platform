# ADR 0010: negotiated authoritative tile movement

Status: implemented and verified locally (M07-04); no rollout approval. Evidence: `docs/agent/evidence/m07-movement-checks.json`.

The cafe renderer previously inferred standing placement and jumped to a claimed seat. Room/seat v1 already has verified consumers. Movement must not make a client-provided map, path, speed or timestamp authoritative, or add unexpected fields to legacy strict snapshot parsers.

Trusted world definitions may carry a validated scene manifest matching their scene reference/version and seat IDs. The synthetic map moves into the non-renderer world SDK; API never imports Pixi. Other worlds without scene geometry keep their existing contracts and deny movement negotiation. The room service uses a bounded orthogonal BFS (at most64×64 tiles, path at most256 nodes) around solid geometry.

`room.join` opts into `motionVersion:1` per connection. Only those connections receive optional `serverTime` and self/visible-participant `motion:{path,startedAt,stepMs:150}`. Older joins receive the original field set on ACKs and deltas even alongside a modern tab of the same account. `room.move` requires this negotiation, existing own-membership/session/epoch validation, world permission, shared command/queue limits, idempotency and the single owner guard. Its only new input is a destination tile; client paths/speeds/timestamps/identities fail strict validation. No movements while seated or overlapping walks. There is no per-tick server broadcast.

Seat ownership remains atomic at acceptance, including keyboard controls. A claim creates an approved path to the registered seat interaction tile; release cancels that path at the last reached tile. This internal timed path also applies when a legacy tab claims a seat, so opting out of motion fields cannot bypass server travel time. Legacy rendering/seat ownership stays immediate and motion metadata stays omitted. This preserves M06 semantics; it does not enforce physical avatar collision or delayed seat reservations. Final transport loss freezes movement at the last complete tile, preserves normal reconnect grace, and a restart still discards ephemeral state.

Motion follows exactly the viewer-filtered participant projection; hidden/blocked paths are not emitted. Clients use the snapshot server clock sample plus local elapsed monotonic time for visual interpolation along approved segments. They never submit interpolated coordinates. Rendering stops on completion, loss, identity change or disposal. Reduced motion uses still presentation; comprehensive accessibility/performance checks remain M07-05/06.

Verification required before VERIFIED: bounded path/interpolation unit checks; real socket invalid wall/destination/forged input, IDOR/replay/rate, old/new tab negotiation, block privacy, final loss freeze and trusted seat point checks; actual desktop/mobile click and keyboard movement/interpolation with all regressions. No DB migration or persistent position; rollout remains OFF. Rollback the commit and reload/re-admit synthetic clients using the matching SDK.
