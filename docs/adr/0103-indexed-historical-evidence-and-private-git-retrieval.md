# ADR0103 — Indexed historical evidence and private Git retrieval

Status: accepted for repository tooling, 2026-11-05. Scope: N01-03; no application or release authorization change.

The historical Mxx evidence contains 3,586 files / 151,876,136 bytes. N01-02 created a separate authenticated local archive and fully restored it, but a fresh checkout must not depend on its private local key. Read-only GitHub repository and recursive-tree queries confirmed the existing repository is private and the immutable `cef7dc17172f7c6cda930c99648a5e3ad609cc55` tree contains every indexed original blob. Local Git-only retrieval checked every byte against the N01-02 SHA-256 index. No new remote content was uploaded.

Use the committed [index](../evidence/index.json) and [Git snapshot mapping](../evidence/git-snapshot.json) as the historical reader contract. Verify existing originals first, then the authenticated private archive when available; only absence allows fallback to local immutable Git objects. Corruption, an existing changed original, invalid key permissions, symlinks, index disagreement and wrong tree/object mapping fail closed. Git operations disable lazy fetching. No reader silently downloads data or creates credentials.

Keep the original commit reachable, the repository private and its existing access controls. CI core/browser checkouts fetch full history; shallow clones need an explicit full fetch or the separate private archive. This increases history transfer relative to shallow checkout. Removing raw files later reduces the current tree, not Git history or full clone transfer. The local encrypted archive remains an additional copy, without a newly provisioned off-host ciphertext destination or independent off-host key custody. Git repository access is the existing portable historical retrieval path, not public sanitization approval or a disaster-recovery service guarantee.

Governance verifies indexed bytes; release checks still enforce all existing approval/role/world controls; ops-watch still labels historical samples and unknown business metrics exactly as before. These operations never rerun historical tests or extend their original source/environment applicability. Fresh test/audit/load writers use ignored `artifacts/evidence/local/<run-id>/` or scoped CI artifact directories, preserving the original observations. Documentation links target the original private immutable Git tree and require repository access.

N01-04 cleanup remains a separate reviewable slice after consumer verification. SQL, lockfiles, source provenance and selected legacy fixture archives are retained. Revert cleanup to restore the original current-tree files; no history rewrite is permitted.
