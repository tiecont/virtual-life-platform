# ADR0137 — versioned GameSession data and pure reducer core

Status: implemented candidate;verification pending. Date:2026-11-09. Task:N15-02;proposal baseline ADR0136. No game mode is registered or exposed by this change.

Add strict schemaVersion/protocolVersion1 command/ACK and public/own/spectator DTOs to existing contracts. Match/ruleset versions remain distinct. Commands carry expected state,generation and room-source assertions;account,clock,role,target or arbitrary private fields cannot become authority through a payload. Public fields have explicit mode allowlists;own hands are per-account,and only the mist private variant admits target knowledge. Crew rejects a target field. Hidden public profiles cannot reveal identifying cosmetic parts. Spectator v1 returns only disabled status. Receipt ACKs may identify an older committed revision alongside a newer current own view;rejected ACKs contain no private view.

Add the CommonJS TypeScript workspace `boardgame-core`,using the repository's existing compiler conventions. It depends only on contracts. Reducer inputs contain bounded immutable plain data,a supplied clock and supplied entropy words. No network/database/React/room owner,system clock,RNG,logging,storage or dynamic import belongs in this package. The source guard is an architectural check,not a JavaScript security sandbox. Concrete mode reducers must live under the same guarded closure in their later tasks.

The framework validates match/table/generation/version,room/current membership,participant,turn/phase,clock and exact deadline cutoff before invoking an explicitly registered reducer. It rejects malformed output,new identities/seats,duplicate private item ownership and invalid projections. Accepted state advances one revision and returns sanitized effect intentions;it performs no persistence,broadcast,timer or reward. Inputs are cloned/frozen,including accessor/cycle/prototype rejection. Shuffle is unbiased rejection sampling over host-supplied CSPRNG words;it does not generate randomness or establish game/seed fairness.

Authentication/current room admission/owner fencing are real host responsibilities. The host must derive the context from existing services and recheck it after waits before durable COMMIT. Pure type/context checks do not replace those guards. Private/public projection helpers use a server-approved profile visibility map,defaulting to hidden identities. Mode rules receive no profile/appearance input that could grant species/cosmetic powers.

Independent Leave/Travel/Block/recovery uses the host lifecycle,not a turn deadline. `game.leave` is a reserved wire intent routed by the future host adapter;the pure turn engine refuses to claim it completed. A separate host-only pure abort helper can produce an unawarded terminal transition after deadline,without a registered mode. N15-03/N15-04 must authorize,persist and clear claims atomically before acknowledging departure.

Unit adapters are explicitly synthetic interface fixtures. They do not implement Color/Mask/Routes,deals,card conservation,role fairness or balance. All actual modes and exposure remain unavailable until gated N16/N17/N18 tasks. No SQL/API route,world registration,UI/native port or release/distribution change is introduced here. Rollback removes the unused package/DTO namespace;existing platform schemas and Phase1 state/evidence remain unchanged.
