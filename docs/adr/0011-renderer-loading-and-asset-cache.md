# ADR 0011: explicit renderer entry and content-addressed avatar cache

Status: implemented and verified locally, M07-06. Evidence: `docs/agent/evidence/m07-performance-checks.json`. No public rollout approval.

The CommonJS scene package root re-exported the renderer, so importing a tile model also loaded Pixi. Model helpers and the renderer now have separate entry points: the root exports pure models/types; `@virtual-city/pixi-scene/renderer` is an explicit public client entry dynamically imported by the portal. Package exports and boundary checks permit that exact path only to the portal, while private/deep imports remain forbidden. The root retains its renderer type export without a runtime require. A real Node model-import check must load zero Pixi modules. Original SVG generation code is separated from runtime frame/palette metadata.

Generated atlas URLs include the first12 hex characters of their SHA-256 in a revision directory. The full digest and original source remain in provenance. The generator/checker reproduces SVG, provenance and bundled URL metadata together. Only `/assets/avatars/:revision/starter-v1.svg` receives a one-year public immutable cache; provenance, API/session data and other public files do not receive that rule. New artwork creates a new URL. Older revisions can be retained through an approved rollout/rollback window; this local change replaces the former unversioned fixture path. No DB migration or entitlement change.

`config/scene-performance.json` defines local regression budgets before collecting the new profile: canvas-ready12s, total loaded JS decoded3MiB/encoded1MiB, atlas decoded512KiB, zero idle renders over1s, requestAnimationFrame p95 gap100ms, and post-forced-GC JS heap growth<20MiB across3 SPA remounts. The harness uses actual authenticated HTTP/socket scenes, CPU4x and simulated40ms/12Mbps loopback transport in Chromium desktop/mobile emulation. It also verifies immutable HTTP headers and a warm second-page atlas transfer of zero bytes.

These are bounded regression hypotheses for this synthetic cafe. Browser CPU throttling is not physical low-end hardware, rAF cadence is not GPU throughput, and forced-GC JS heap excludes GPU/total browser memory and does not certify absence of leaks. Report actual counts/bytes/time/artifacts, including failed attempts. Performance gates for real worlds/production devices remain M22/release operations. Original art is starter content, cafe layout is still a local fixture, and media/release approval remains false.
