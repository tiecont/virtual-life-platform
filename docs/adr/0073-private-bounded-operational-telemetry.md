# ADR0073 — Private bounded operational telemetry

Initial404/type failures and first unexplained browser locator timeout retained. External collector/dashboard/alerts remain NOT_RUN. Existing worlds/approvals stay closed. See [evidence](https://github.com/tiecont/virtual-life-platform/blob/cef7dc17172f7c6cda930c99648a5e3ad609cc55/docs/agent/evidence/m21-telemetry-checks.json) and [runbook](../operations/OBSERVABILITY.md).

Audit found Pino JSON logs with generated request IDs and resource/query redaction,plus fixed-label process-local RoomMetrics histograms/diagnostics. There is no protected operator export,real trace processor or accurate durable order-state gauge. Reuse those owners rather than query another domain's tables from an infrastructure repository.

Add exact compatible OpenTelemetry API1.10.0/SDK-trace3.0.0,verified against official registry metadata/engines/peer range and primary docs. Use one per-app provider with manual root spans and a bounded local exporter,without global provider registration,automatic HTTP/SQL/browser instrumentation,baggage or caller trace-parent authority. Actual SDK spans must reach the exporter;no no-op tracing claim. This is local root-span tracing,not distributed propagation or a configured external collector. No dependency/ORM/runtime version replacement is authorized.

Collection/export defaults disabled without an independent optional64hex operator token. Token-protected internal endpoints have bounded quotas and no cookie/guest/staff-role shortcut. They are outside Caddy's public API paths and never part of player UI/global presence. No actual production token,staff privilege or third-party destination is provisioned. Constant-time token comparison and no-store responses protect the local boundary;TLS/private networking/operator secret handling remain operational prerequisites.

Only finite route classes/methods/status classes and the existing six Room commands may label metrics. No URL,query,account/session/peer/world/source ID,body,cookie,authorization,chat text,dating preference or client error message is exported. Dating HTTP paths and private telemetry endpoints are excluded from their own counters/spans. Logs retain request IDs but sanitize error details. Trace correlation uses server-generated IDs,not caller-supplied trace context. Generic successful Room results may supply only an ephemeral HMAC room pseudonym;private DateRooms never enter generic Room telemetry.

Bound HTTP/room traces in flight and retain at most100completed records for five minutes. No raw unbounded request sample history or metrics labels chosen by clients. p95 values are histogram upper bounds,not invented exact percentiles;overflow is explicit. Metrics/traces are process-local and reset on restart. Failed or dropped instrumentation must not change product authority/effects.

Online/membership/seat gauges come from RoomService diagnostics,not socket totals that could count private dating sessions. Hospitality supplies its own bounded read-only aggregate of retained order phases,with SQL timeouts and no identifiers;retries must not increase a durable order-state count. Infrastructure composes owner ports and never directly imports another domain's repository/tables. No database migration is planned.

Verification must exercise actual HTTP+authenticated Room commands+persisted orders;default/wrong-token denial;real exported spans/request IDs/pseudonymous room IDs;finite labels/p95/error counts;no sensitive fields under forged URLs/headers/body/trace context;dating exclusion;bounded retention/capacity;aggregate outage/recovery and shutdown. Unit-only DTOs or a protected empty endpoint cannot satisfy this task. Evidence records exact scope/commands and any failures.

Primary references:[OpenTelemetry JS manual instrumentation](https://opentelemetry.io/docs/languages/js/instrumentation/),[SDK-trace standalone behavior](https://open-telemetry.github.io/opentelemetry-js/modules/_opentelemetry_sdk-trace.html). Exact registry versions/publication dates/integrities are in m21-telemetry-dependency-audit.json. No real external export or public monitoring claim follows.
