# ADR0098 — Independent wave candidates with human release gates

Status: accepted for offline implementation (M23-01).

The actual Deadline/Maid adapters are locally verified. M23 needs a release inventory without confusing source reuse permission or synthetic staff grants with public operation. Existing local installers reject production and all actual rollout flags remain OFF.

Add a machine-readable wave/control/role inventory and read-only governance check. W2 has an exact shared-baseline module set and no later-wave dependency;W3–W6 have separate world/content/operator gates. The check rejects public activation,fabricated role assignment and inherited dating approvals in this offline candidate scope. Negative tests verify those boundaries and W2 independence even when later-world evidence is missing.

The report lists pending technical modules separately from the external public gates. Passing the checker never supplies signoff or provisions staff. Six public responsibilities remain explicitly unassigned. Any future public release must replace this closed candidate policy through explicit review,not bypass its assertions or treat local environment flags as a deployment interface. No application contract,DDL,world flag,secret or media rights change.
