# ADR0027 - Private calendar-day focus summaries

M10-05 derives daily statistics from retained canonical completed focus rows. GET /v1/focus/summary accepts strict from/to ISO calendar dates,optional IANA timeZone(default Asia/Ho_Chi_Minh) and worldSlug. It always uses the authenticated account; no user/peer selector,public leaderboard,task text or economic reward is introduced. Global/per-world presence consent cannot publish a private summary.

Dates are inclusive,range max31days,not future,limited to complete local days within the existing90day retained window. The response explicitly includes availableFrom,selected zone/world and UTC bounds for each local day,zero-filled counts/focusSeconds and totals. Partially retained oldest day is rejected rather than reported as a complete zero. Timezone names must be UTC or slash-qualified names in PostgreSQL's time zone catalog; query parameters are bound,not interpolated SQL. Date validity is checked before SQL. Bounds come from consecutive local calendar midnights converted to UTC: no assumption that a day is24hours. DST23/25hour and repeated-hour behavior is tested against the actual database.

Completion is assigned by canonical changedAt(endsAt),not the browser callback/read time. An account's at mostone active/paused row is reconciled under its transaction before aggregation; completed counts sum each retained row once and only its configured duration. Cancelled/paused/active rows do not count. Optional pause time does not inflate focusSeconds. Repeated reads after reconciliation write neither timer nor aggregate/tick records. There is no separate persistent aggregate that can survive account erasure or retention purge.

Additive0013 adds a partial account/completed-time index. Existing bounded90day terminal cleanup/receipt cascades remain engine-owned; a105row terminal fixture verifies100then5 batching. Identity deletion cascades existing rows. Rollback closes summary entry and retains this harmless additive index/history; no destructive migration or legacy DB change. Actual live Deadline/Library integration staysM15/M17; synthetic tests cannot certify it. Local default retention and public operations remain owner-review gates; all rollout flags stayOFF.
