# virtual-life-platform product contract

One identity can discover and enter distinct 2D worlds, do a shared activity, leave safely, and meet consenting friends again. Shared identity never means shared disclosure. A guest can begin without registration. First public beta requires two real integrated worlds; a link or test scene is not integration.

North-star hypothesis: weekly returning identities completing a verified shared activity in an eligible world. Count successful server-acknowledged completion once per request/source; measure return rate in aggregates only. No retention or CCU target is a measured achievement yet. Avoid rewarding unwanted attention or time spent online.

Scope waves: W0 audit/foundation; W1 synthetic city safety slice; W2 Deadline + Maid actual beta; W3 Library/Park/events; W4 Restaurant; W5 restricted Lounge; W6 separately gated adult dating. W1/W2 cannot wait on W5/W6. Detailed roles/policies live in WORLD-MATRIX and JOURNEYS. Source reconciliation: Deadline remains silent focus/seats/stats without public chat; Maid remains voluntary Customer/Maid hospitality with moderated chat, all genders, no pay-for-affection. City social services apply at platform edges without adding forbidden features to those worlds.

Release truth: labels distinguish unavailable, test destination, verified preview and authorized live world. Show unknown occupancy when authority is unavailable; empty is legitimate. Prefer occupied rooms within privacy and capacity rules. Never seed fake online visitors. Guest continuity is browser-bound until actual upgrade/migration works; do not promise existing Cafe sessions are already connected.

Hard exclusions: voice/video/DM, arbitrary uploads, UGC worlds, real-money economy/trading, AI companions, copyrighted media redistribution, gambling, social-login assumption, continuous MMO simulation, Kubernetes/Kafka/Elasticsearch.

Public release requires a named operator, moderation coverage, privacy/content review, security tests, restore drill, monitoring and explicit deployment approval. See CONTENT-POLICY and RISKS. No public release is authorized by this document.
