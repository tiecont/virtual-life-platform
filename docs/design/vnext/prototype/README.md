# N06-02 — activity state prototype

Run `pnpm ux:prototype` from the repository root for an isolated Chromium walkthrough. Run `pnpm ux:prototype --serve` to open a loopback-only preview URL printed by the command; stop that process when done. The server serves only five explicitly allowlisted prototype/CSS files, not the repository or environment files. No API, database, auth credentials or gameplay mutations are used.

This prototype consumes the real CSS exports from `packages/ui` and original code-authored SVG concept art. It is not mounted in production player routes and does not alter existing renderer/room geometry, seat IDs, source artwork or rollout flags. Six illustrated tables are a composition study, not authoritative Deadline geometry. [Provenance](provenance.json) preserves that scope and release approval remains false.

Use the external preview controls for ready/loading/empty/full/wait/offline/reconnect/denied states and Deadline/Maid perspectives. Queue data and confirmations are simulated. Guest/voluntary-service choice, independent cancel/leave/safety, 30 native desk choices, private focus HUD and compact settings demonstrate interaction hierarchy. Production behavior remains the existing server owners' responsibility after N06-03 dependencies pass.

The desktop grid becomes a single-column scene/activity layout at 360px. Dialogs become bottom sheets with safe-area padding, bounded scrolling, native modal focus and Escape/close restoration. Enlarged text wraps navigation and seat controls; content is not clipped to hide overflow. Reduced motion follows the system by default; the setting is explicit. Sound is OFF with no assets or autoplay; an eventual audio opt-in cannot bypass asset clearance. Text, controls and SVG description remain usable without canvas input.

Verification checks two viewport profiles, eight state designs each, real keyboard Enter/Tab/Escape and modal focus, seat/focus/cancel, unavailable-state leave, voluntary shift start/stop, settings, safety, 200% text, target sizes, semantic accessibility snapshots, no page errors and denial of arbitrary static files. The first runs found mobile 200% navigation overflow and a lint browser-global error; both failed attempts remain in task evidence and were corrected without hiding content or relaxing assertions.

Fresh screenshots, semantic trees, layout observations and facts stay in private `artifacts/vnext/n06-02/`. Screenshots were inspected for the desktop/mobile ready layout and large-text mobile dialog. Browser semantics and scripted walkthroughs are not TalkBack/VoiceOver, physical-device, human usability, performance, retention or production gameplay certification. Those gates remain with N06-05/N10/N14 and later runtime acceptance.
