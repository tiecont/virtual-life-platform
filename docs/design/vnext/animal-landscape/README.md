# Virtual Life — animal / landscape design study

Run `pnpm ux:animal-study` for the isolated Chromium walkthrough, or `pnpm ux:animal-study --serve` for a loopback-only interactive preview. Stop the serve process when done. Only the five named static study files are served; environment/source traversal is denied. No API, remote font, analytics, socket, profile persistence or world mutation is involved.

Open **My character** to vary14groups, including species/body/head/eyes/muzzle/ears/tail/fur/markings/hair/clothes/accessory and pose/view. Apply updates only this illustration; Cancel leaves it unchanged. Species swaps normalize incompatible ears/tails together. Static key-pose views demonstrate a rig proposal, not a completed production animation atlas. Waiting/confirmations/guests are simulated. Every report/equip/admission/protocol decision remains with the existing server owners.

The proposed style has warm broad lighting, linen/oak/clay/sage materials, species silhouettes and a scene-first landscape dock. Portrait retains useful controls with a nonblocking rotation hint. Design states cover loading/empty/full/wait/offline/reconnect/denied. The same visual language is intended for Deadline/Maid and later Lodge, with actual scene geometry/layout adaptation deferred to implementation.

[Art/rig/compatibility brief](ART-AND-RIG.md) defines layer anchors, supported combinations, animation production, migration/recovery, readonly v1 fallback and ownership constraints. [Budgets](budgets.json) freeze additive art-resource hypotheses before production implementation; all existing `docs/mobile/android-spike.json` thresholds stay unchanged. These targets are not measured results.

[Provenance](provenance.json) records original code-authored vector drawings/styles and file hashes. Existing N06-01/02 prototypes, pixel atlas, license records and release flags remain intact. No third-party art/audio/font is copied or purchased. Owner art review and distribution approval remain pending.

Browser walkthroughs inspect5target viewports plus one short keyboard-occlusion fixture, eightstates each, part geometry/selection,48static species/pose/facing combinations, actual modal keyboard/Escape/focus restoration,200% text, bounds of important controls,44px targets, denied file paths and zero external requests. Screenshot/semantic trees and failures remain private under `artifacts/vnext/n06-06/`; report summaries/hashes enter vNext evidence after actual execution/review.

A short viewport is not a real virtual keyboard/cutout measurement. This design-only tool does not qualify native orientation/lifecycle, TalkBack/VoiceOver, physics/scene geometry, production item entitlements,20-avatar frame performance, retention or5-user usability. N06-03/07/08/09, N10-03/04 and N14 retain their independent gates. N06-06 may be VERIFIED only for the design/review deliverables.
