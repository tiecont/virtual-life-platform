# Security regression matrix

`pnpm test:security` builds existing packages and runs nine existing/new integration files through the isolated disposable PostgreSQL harness. The security project reuses the normal integration tests;it does not replace CI's root gate. All tests retain the15second case/hook deadline. Actual run counts and exits belong in [M22-03 evidence](../agent/evidence/m22-security-checks.json).

| Risk | Executable evidence |
|---|---|
| CSRF/cookie/Origin/authority | `security-network.test.ts` uses actual TCP PATCH and socket handshakes with mixed users' cookies/CSRF,bad Origin,tampered cookies and role/account claims. Valid identity/room controls still work and neither profile changes. `identity.test.ts` and `identity-socket.test.ts` cover strict schemas,legacy tokens,expiry,rotation,logout and per-command reauthentication. |
| IDOR/private projections | `rooms.test.ts`, `social.test.ts`, `reports.test.ts` and `travel.test.ts` cover exact epoch/membership/session/capability,viewer-specific hidden/block policy,reporter-only receipts/assigned-case RBAC and private export. New TCP test tries another member's room proof before a valid own snapshot. |
| Rate/transport abuse | Actual TCP requests vary forwarded headers on one physical sourceIP;ten guests allowed/eleventh denied. Sixty session checks alternate two real sockets;the61st is denied. Existing socket/session/queue tests preserve current bounds;client headers do not confer trusted-proxy status. |
| Current restrictions/reconnect | New TCP test inserts a synthetic committed world restriction and verifies existing socket,new socket,HTTP directory and restarted owner deny access;logout remains independently available. `sanctions.test.ts` separately exercises audited issuance,ejection/expiry/appeals/independent recovery. A raw SQL fixture is not a real moderator operation. |
| Adult-world access/privacy | Ordinary runtime denies claimed adult headers/room payloads and creates no matching enrollment. `dating-adversarial.test.ts` supplies nine invalid/malformed/underage/mismatched/stale synthetic proof decisions,known-handle outsider attacks,same-account foreign sessions,friend privacy and account-scoped bans. These are local protocol decisions,not real age/identity verification efficacy. |
| Deep links/late replies | Actual desktop/mobile private browser journey logs out while a committed private read is held;late reply cannot restore aliases/positive controls. Positive API returns401,private deep link404,public navigation contains no private source/alias. Existing scene/safety browser regressions cover block filtering,reconnect and current emergency closure. |

Direct network tests bind synthetic loopback source addresses,run a separate child API and use one generated schema per case. They never target retained city/legacy data. Negative mutation assertions check HTTP status and committed state;socket denial alone is paired with valid controls. New helpers emit fixed errors without cookies/CSRF/raw request bodies. Test artifacts and browser traces are private synthetic diagnostics,not sanitized public reports.

No product code,policy,world flag,migration,real staff/provider or public endpoint activation is required. `NOT_FOUND` intentionally conceals a currently inaccessible world;it is not evidence that the test failed to exercise authorization. Shared access checks still consult current SQL on each command/reconnect;in-memory possession of a room handle is insufficient.

This matrix is a regression inventory,not a complete security audit. Real eligibility/legal/privacy assessment,moderator coverage,key custody,dependency/secret scans and public release remain their own gates. Do not claim that an old container image contains newer source or infer100/1000CCU capacity from security tests.
