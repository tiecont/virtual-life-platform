# Implemented GameSession v1 foundation signatures

N15-02 candidate. Actual source:`packages/contracts/src/games.ts` and `packages/boardgame-core/src`. This is a DTO/core interface,not an installed game API or playable mode.

`GameCommandSchema` requires schema/protocol1,requestId,matchId,tableId,generation,expectedVersion and own room-source assertions. Its discriminated payloads are `color.play/draw/playDrawn`,`mask.submit/challenge/trust`,`route.place/scan/redraw` and reserved `game.leave`. Unknown fields,schemas,coordinates,rotations,duplicate claim IDs and authority/clock/role/target injection fail parsing. Semantic card/turn/game legality still belongs to the registered mode rules;the DTO is not a complete rule implementation.

`GamePublicViewSchema` is an explicit per-mode board/seat/count/phase/deadline/result allowlist. There are no public hand IDs,deck order,role,target or RNG fields. Profiles/appearance are supplied only through an approved visibility map and default to null. `GameOwnViewSchema` adds only the requesting account's private variant:Color/Mask hand;Routes crew hand/own role,or mist hand/own role/targetGateId. Crew rejects a target field. `GameSpectatorViewSchema` only admits `{schemaVersion:1,projection:'spectator',enabled:false}`. Later spectator capacity/privacy work requires a new reviewed contract.

`GameAckSchema` returns a positive committedVersion plus a fresh own view,possibly newer on receipt replay. A rejected ACK has no private view. The raw `GameDecision.state` contains server secrets and must never be sent over HTTP/socket or logged;host responses must parse an authorized projection through the DTO. N15-03/N15-04 own actual transport/auth/receipt tests.

`GameRulesEngine(rules=[]).decide(state,command,context)` returns either the original state/reference with a denial and no effects,or one new immutable revision and sanitized effect intentions. Context has the authenticated host account/current room source,injected clock and CSPRNG words. Real host session/room/owner/deadline rechecks remain mandatory before COMMIT;this pure function cannot perform them. Rules are pinned by mode+rulesetVersion and none are registered by default.

`projectGamePublic`, `projectGameOwn` and `projectGameSpectator` return versioned allowlisted views;invalid/corrupt state fails closed. `abortGame(state,clock)` prepares an unawarded host lifecycle abort independent of turn/deadline. The host must authorize and atomically persist it/clear claims. Reserved `game.leave` is routed through that host lifecycle,not acknowledged by the turn reducer. `shuffleWithWords(items,words,cursor)` uses deterministic rejection sampling;host entropy quality and mode solvability remain separate requirements.

New core source cannot import network/DB/React/apps,system clocks/RNG,logging or dynamic modules. The static guard covers its recursive source closure and only admits game data-schema value imports from contracts. It is not a runtime sandbox. Synthetic unit adapters exercise routing/immutability/projection/denial interfaces;they do not implement Color/Mask/Routes,deals,conservation or balance. No SQL,world route,UI/native adapter,exposure flag,mandatory platform capability or Phase1 state changes in this slice.
