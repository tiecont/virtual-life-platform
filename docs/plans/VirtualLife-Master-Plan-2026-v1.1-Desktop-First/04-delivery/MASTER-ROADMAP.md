# Master roadmap — VirtualLife desktop-first v1.1

**This file supersedes the v1.0 web-first stage order.** The complete stage plan is `DESKTOP-FIRST-ROADMAP.md`.

- **G0** architecture audit, desktop ADR approval, repo/legacy ledger reconciliation, named target Windows hardware, original brand and asset rights.
- **G1** Rust core and native Unity project/network/shader proof; Next.js official website shell.
- **G2** Windows native Aurora Plaza: move, avatar expressions, NPC life, camera, map M, LOD quality tiers.
- **G3** City→café→sit→card→stand→map/teleport→Pet Arena loop, with authoritative Rust receipts.
- **G4** native Windows 30/60m benchmark, safety/privacy, game client installer/patch, launch portal UX and closed beta approval.
- **G5** optional macOS/Android/iOS evidence gates; not required for Windows.
- **G6** signed Windows official release with website launch, support, canary, rollback and monitoring.
- **G7** more content & Rust multi-owner scale only under measured demand.

**Agents should not blindly finish the browser-world roadmap before Unity.** Existing N06-04/N06-09 legacy work remains a separate owned branch; desktop client does not invalidate its verified artifacts.
