# Official website and desktop marketing art direction

## Three launch moments
1. **Discovery**: cinematic hero poster/video of Aurora Plaza, large `VirtualLife` logo, headline `Your World. Your Story.`, vivid but controlled gradient, CTA Download Windows and Explore Aurora City.
2. **Belonging**: interactive scroll gallery of cat/fox/bunny originals with micro-expression loops and city café screenshots; reduced-motion static alternate.
3. **Play together**: simple row `Explore → Enter Café → Sit & Play → Pet Arena`, with visually distinct screen frames. Clearly identify concept renders versus **actual gameplay captures** until approved.

## Motion budget
Only subtle particle/cursor parallax around hero (opt-in), CSS transform animations, image cross-fades, poster-first video. No auto-loading multi-MB 3D engine, no heavy shader canvas as root background. Text has contrast over media overlays; hover-only features get touch fallback.

## Download page details
Win x64 build version, SHA256/download size (from signed manifest after release), system requirements and graphics profiles after benchmark, installer troubleshooting, patch notes, privacy/consent, device support caveats. Show install steps and store buttons only where actually supported.

## Deliverables
`07-visuals/VirtualLife-official-site-prototype.html` is an offline direction prototype with links and mock UI; it **does not** host a real game/download/signup service. Existing logo and city preview from v1.0 remain temporary concepts.
