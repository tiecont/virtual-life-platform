# VirtualLife v1.1 state rules

Statuses: `TODO`, `RESERVED`, `IN_PROGRESS`, `BLOCKED_EXTERNAL`, `IN_REVIEW`, `VERIFIED`, `FAILED`, `DEFERRED_APPROVED`.

All 110 VL tasks in this plan ship **TODO**. The plan has not audited a live repo HEAD and no tests were run against real VirtualLife game code. A coordinator can reserve one task/file scope after dependencies verified and branch/owners are known. `VERIFIED` demands source SHA, actual test/log evidence, independent reviewer and (for graphics) physical Windows GPU profiles. A worktree conflicting with active N06-04/legacy plan is blocked until handoff. The legacy Nxx/PA/Lodge state is never synchronized by guessing or mass-setting statuses. See `AGENTS.md`.
