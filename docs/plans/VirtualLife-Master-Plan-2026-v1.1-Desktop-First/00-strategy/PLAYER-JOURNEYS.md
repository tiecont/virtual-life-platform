# VirtualLife desktop-first player journeys

## First visit from official website
Website shows original Aurora Plaza hero, brand, supported device requirements, FAQ, Download Windows CTA → signed installer (future, release gate) → Unity startup/login via safe external-browser auth → Rust scoped world ticket → Stream essential plaza assets → spawn expressive fox/cat avatar → optional onboarding controls. No full game shader loaded by website.

## City to café to card game
Third-person WASD/gamepad or click-to-move toward Lumi Café; mouse camera; E door → scene stream + server presence transfer → highlight seat, choose and reserve → character sits with hand/tail IK → invite/join small board game → watch visible table/card animation, private hand masked from spectators → result/receipt → stand and leave. Controls are remappable; M unavailable while typing in chat.

## Map M to Pet Arena
Press M → browse POI images/previews, choose Pet District → Navigate or Teleport (different behavior) → Rust validates access, holds destination, client preloads assets, server commits transfer or aborts → run to arena kiosk → Pet combat board/cinematic camera while avatar/Pet visible → deterministic Rust result & settlement → exit game back to walkable world.

## Reconnect & safety
Disconnect during seat/battle/teleport → UI reconnect path, Rust canonical state, unknown reward same receipt ID; report/block or account revocation updates projection and session ownership; player cannot use a modified Unity client to bypass rules or obtain private cards.

## Accessibility/device differences
Subtitles, motion reduction, camera/cursor sensitivity, keyboard and controller, text scale/contrast; Low quality never removes social affordance. Mac/mobile and web-light gameplay are independent later candidate gates, not implied by site availability.
